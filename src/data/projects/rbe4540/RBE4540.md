## Overview

How do robots pick things up reliably? This course covers the theory behind grasping and the vision that guides it, with hands-on work in **ROS 2**, a **Gazebo** simulation of a robot arm with a palm camera, and **OpenCV**.

## Concepts

- **Grasp taxonomies:** classifying human grasps (power vs. precision, which fingers oppose, thumb position) and using object properties to choose a robot gripper
- **The grasp matrix:** a linear map from the forces at each fingertip to the net force and torque on the object, built from each contact's position and orientation and a contact model (frictionless, hard finger, or soft finger)
- **Grasp quality:** the singular values of the grasp matrix describe how well a grasp resists disturbances; different metrics (weakest direction, overall strength, or how evenly balanced it is) can disagree on the "best" grasp
- **Vision features:** color thresholding, edge, corner, and circle detection to locate an object from the palm camera
- **Visual servoing:** closing the control loop on the image itself, turning the error between where features are and where they should be into camera velocities through an image Jacobian
