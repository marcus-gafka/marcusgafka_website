## Overview

How should a robot decide what to do? This course builds up the core tools of AI for robotics: searching for plans, reasoning against adversaries and chance, and making decisions under uncertainty with Markov decision processes and reinforcement learning. Everything is implemented in **Python**.

## Search

Search algorithms explore a graph of states to find a path to a goal. Uninformed methods (breadth-first, depth-first, and uniform-cost search) know nothing about where the goal is; informed methods use a heuristic estimate $h(n)$ of the remaining cost. **A\*** expands nodes in order of

$$f(n) = g(n) + h(n)$$

where $g(n)$ is the cost so far. If $h$ never overestimates the true remaining cost ($h(n) \le h^*(n)$, *admissible*) and satisfies $h(n) \le c(n, n') + h(n')$ (*consistent*), A\* is guaranteed to find the cheapest path.

**Example.** On a grid where a robot can also move diagonally and every move costs 1, the Manhattan distance $|\Delta x| + |\Delta y|$ is *not* admissible: it counts a diagonal step as 2. The Chebyshev distance

$$h(n) = \max\left(|\Delta x|,\ |\Delta y|\right)$$

matches the true cost in open space and never overestimates around walls, so A\* with this heuristic stays optimal.

## Adversarial Search

In games, the other player is working against you. **Minimax** assumes the opponent plays perfectly:

$$V(s) = \begin{cases} \max_{a} V(s') & \text{on my turn} \\ \min_{a} V(s') & \text{on the opponent's turn} \end{cases}$$

**Alpha-beta pruning** tracks the best value each side can already guarantee ($\alpha$ for the maximizer, $\beta$ for the minimizer) and skips any branch once $\alpha \ge \beta$. With good move ordering it searches roughly $O(b^{m/2})$ nodes instead of $O(b^m)$, effectively doubling the reachable depth. When the "opponent" is random rather than adversarial, **expectimax** replaces the min with an expectation, $V(s) = \sum_{s'} P(s')\,V(s')$.

## Local Search

When only the final state matters, local search improves a single candidate step by step. **Hill climbing** always moves to the best neighbor, so it can get stuck on a local peak. **Simulated annealing** escapes by sometimes accepting a worse move, with probability $e^{\Delta E / T}$, while a temperature $T$ slowly cools toward pure hill climbing.

## Markov Decision Processes

When actions have uncertain outcomes, an MDP models states $s$, actions $a$, transition probabilities $T(s, a, s')$, rewards $R(s, a, s')$, and a discount factor $\gamma$. The optimal values satisfy the **Bellman equation**, which **value iteration** solves by applying it repeatedly until the values stop changing:

$$V_{k+1}(s) = \max_{a} \sum_{s'} T(s, a, s')\left[R(s, a, s') + \gamma\,V_k(s')\right]$$

**Example.** The discount factor sets how patient the agent is. Standing 3 steps from an exit worth +5 and 1 step from an exit worth +2:

| $\gamma$ | Far exit, $5\gamma^3$ | Near exit, $2\gamma$ | Best choice |
|---|---|---|---|
| 0.9 | 3.65 | 1.80 | walk to the far, bigger reward |
| 0.5 | 0.63 | 1.00 | take the near, smaller reward |

## Reinforcement Learning

Reinforcement learning handles MDPs whose transitions and rewards are unknown, learning them from experience. **Model-based** learning counts outcomes to estimate $\hat T(s, a, s') = \frac{N(s, a, s')}{N(s, a)}$ and averages observed rewards, then solves the estimated MDP. **Model-free** learning skips the model: temporal-difference learning nudges each value toward what was just observed,

$$V(s) \leftarrow V(s) + \alpha\left[r + \gamma\,V(s') - V(s)\right]$$

## Applied: A Bomberman AI

In a team of three, we built one AI to escape five increasingly dangerous versions of a Bomberman level, from an empty map to a map with a random monster and an aggressive one that chases you.

- **A\*** with a Chebyshev heuristic plans the shortest route to the exit whenever no monster is within 7 tiles
- When a monster gets close, the character switches to **value iteration** on an MDP whose state is the character's and monster's positions: +10,000 for escaping, −10,000 for entering the monster's attack range, −1 per step, $\gamma = 0.9$
- Monster behavior is the uncertainty: a nearby monster is modeled as chasing (via a local BFS), a distant one as moving randomly
- Because the walls never change, the value table is computed once and cached; limiting it to character/monster pairs within 7 tiles cut 18,496 possible states to 11,488
- A headless test harness ran thousands of games without rendering, wired into pytest and CI so every change had to pass before merging

| Variant | Escape rate (1,000 games each) |
|---|---|
| 1. Alone | 100.0% |
| 2. Random monster | 99.7% |
| 3. Self-preserving monster | 93.8% |
| 4. Aggressive monster | 66.4% |
| 5. Random + aggressive monsters | 81.7% |

One algorithm handled all five variants, with an overall 86.3% success rate, without ever using bombs.
