## Overview

How should a robot decide what to do? This course builds up the core tools of AI for robotics, implemented in **Python**:

- **Search:** breadth-first, uniform-cost, and A*, where an admissible heuristic that never overestimates guarantees the cheapest path
- **Adversarial search:** minimax, alpha-beta pruning to skip branches that can't matter, and expectimax when the opponent is random
- **Local search:** hill climbing and simulated annealing, which occasionally accepts worse moves to escape local optima
- **Markov decision processes:** modeling uncertain outcomes with transitions, rewards, and a discount factor, and solving them with value and policy iteration
- **Reinforcement learning:** learning values from experience when the model is unknown, either by estimating the model or updating values directly (temporal-difference learning)

## Applied: A Bomberman AI

In a team of three, we built one AI to escape five increasingly dangerous versions of a Bomberman level, from an empty map to one with a random monster and an aggressive one that chases you.

- **A\*** plans the shortest route to the exit whenever no monster is nearby
- When a monster gets close, the character switches to **value iteration** on an MDP over the character's and monster's positions, rewarding escape, heavily penalizing the monster's attack range, and modeling the monster as chasing or wandering
- Because the walls never change, the value table is computed once and cached, restricted to nearby character/monster pairs to cut the state space by about 38%
- A headless test harness ran thousands of games without rendering, wired into pytest and CI

| Variant | Escape rate (1,000 games each) |
|---|---|
| 1. Alone | 100.0% |
| 2. Random monster | 99.7% |
| 3. Self-preserving monster | 93.8% |
| 4. Aggressive monster | 66.4% |
| 5. Random + aggressive monsters | 81.7% |

One algorithm handled all five variants, with an overall 86.3% success rate, without ever using bombs.
