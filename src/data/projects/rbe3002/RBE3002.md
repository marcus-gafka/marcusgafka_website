## Overview

In a team of four, programmed a TurtleBot3 (a differential-drive robot with a LIDAR sensor) using ROS to autonomously explore and map an unknown arena, then localize and navigate within it.

## Goals

- Program a Dynamixel TurtleBot3 to complete the mapping and navigation demo
- Use ROS, Linux, and Git to organize code creation, management, and integration
- Create a custom path planning algorithm, motion controller, and communication protocol

## Phases 1 & 2: Exploration and Mapping

<figure class="figure-inline"><img src="/assets/projects/rbe3002/mapping.jpg" alt="Map with frontiers"><figcaption>C-space and frontiers (red)</figcaption></figure>

- Detect obstacles and create a keep-out zone (C-space)
- Identify frontiers: unexplored areas at the edge of the map
- Intelligently select a frontier and plan an efficient path
- Follow the path accurately while maintaining speed
- Save the mapped environment when exploration is done

## Phase 3: Localization

<figure class="figure-inline"><img src="/assets/projects/rbe3002/localization.jpg" alt="Localization in saved map"><figcaption>Localizing in the saved map</figcaption></figure>

- Place the robot at a random location
- Run a calibration maneuver while collecting sensor data
- Determine the robot's position in the saved map
- Quickly traverse the mapped area

<figure class="figure-inline"><img src="/assets/projects/rbe3002/turtlebot.jpg" alt="TurtleBot in the arena"><figcaption>Final demo</figcaption></figure>

During the final demo the robot stayed centered in narrow hallways while continuously updating its location and map.

## Results

- Finished in **6 minutes** against a 15-minute time limit
- Demonstrated well-tuned path planning and path-following algorithms
- Received an **A+** after the preliminary design review, live demo, individual code review, and project report
